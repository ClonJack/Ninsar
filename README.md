# 🎮 Инвентарь (Панель управления)

## ➕ Добавление

- Кнопки **Add** увеличивают количество предметов  
- Значения можно настраивать в Inspector  

## ➖ Удаление

- **Remove** — уменьшает общее количество предметов  
- **REMOVE SELECT ITEM** — удаляет предмет из выбранного стака  

## 🔍 Фильтрация

- Кнопки фильтра позволяют сортировать предметы по категориям  

## 🧹 Очистка

- Полностью очищает инвентарь  

## 📦 Capacity

- Управляет максимальной вместимостью инвентаря
